🚀 Overview

This repository houses the source code for my professional portfolio. Beyond acting as a digital resume, this project serves as a technical artifact demonstrating "Vibecoding"—the modern paradigm of software development where complex architecture, design systems, and interaction logic are orchestrated through strategic natural language prompting with Large Language Models (LLMs).

As a Business Intelligence Analyst, my core competency is translating complex datasets into actionable narratives. This portfolio applies that same philosophy to frontend web development: using lean, semantic code to deliver a high-performance, executive-level user experience.

🧠 The Vibecoding Manifesto

This project was built without writing manual boilerplate. Instead, I operated as a System Architect, leveraging Google Gemini as a pair programmer to construct the application. This demonstrates my ability to:

Prompt Engineer complex systems: Defining layout grids, responsive breakpoints, and color theory via natural language.

Understand Technical Constraints: Directing the LLM to use specific APIs (like IntersectionObserver) for performance rather than relying on heavy third-party libraries.

Iterate Rapidly: Moving from wireframe to deployment-ready code in hours, reflecting agile, modern development cycles.

🏗️ Technical Architecture

To prioritize raw performance and maintain a zero-dependency build pipeline, the project is architected using the modern vanilla web stack.

Stack Breakdown

Structure: Semantic HTML5 ensuring maximum accessibility (a11y) and SEO optimization.

Styling: Tailwind CSS (via CDN for rapid prototyping). Utilizes arbitrary values and custom theme extensions for a bespoke "editorial" design system (Slate/Brand Blue palette).

Interactivity: Vanilla JavaScript (ES6+). No heavy frameworks (React/Vue).

Typography: Google Fonts (Playfair Display for editorial headings, Inter for highly legible UI data).

Staggered Scroll Reveals

IntersectionObserver API + CSS transform/opacity transitions.

Controls narrative flow; ensures the user digests information in the intended sequence.

Glassmorphism Panels

Tailwind's backdrop-blur-xl + bg-opacity.

Creates visual depth and a modern, "native app" feel for modals and sticky navigation.

Encourages exploration of professional history through micro-interactions.
